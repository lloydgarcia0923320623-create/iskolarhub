### IskolarHub

A Flutter scholarship directory and student-support app featuring preliminary
scholarship matching, saved-application checklists, offline access to cached
records, and Firebase-backed services.

- **Built with:** Flutter, Dart, Firebase, SQLite
- **Platforms:** Android and iOS
- **Repository:** [lloydgarcia0923320623-create/iskolarhub](https://github.com/lloydgarcia0923320623-create/iskolarhub)

Matching is informational only and does not determine official eligibility or
guarantee an award. Students should always check the scholarship provider's
official requirements and application channel.
