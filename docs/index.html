01 / ISKOLARHUB Flutter • Firebase • SQLite

A student-first hub to discover and track scholarships.

IskolarHub is a Flutter app concept that helps students explore scholarship opportunities and stay organized throughout an application. Profile-aware discovery, a personal shortlist, and a document checklist work together; Firebase supports connected features while SQLite keeps selected information available offline.

  • Compare student details with listed scholarship criteria
  • Save opportunities and review them in a personal shortlist
  • Track application documents and next steps
  • Keep selected records available with local storage

04 BUILD NOTES

Thoughtful in
the details.

Some of the engineering decisions behind IskolarHub—from access boundaries to the experience when you're offline.

See how to run it ↗
  1. 01

    Offline-aware experience

    Locally cached scholarship records and checklist data keep useful details available without a connection.

    ◎
  2. 02

    Role-based administration

    Administrator tools rely on server-managed Firebase claims, rather than student-controlled profile data.

    ◇
  3. 03

    AI with clear limits

    Guidance uses retrieved in-app materials and doesn't claim to decide eligibility or award outcomes.
